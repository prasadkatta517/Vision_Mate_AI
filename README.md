# 👁️ VisionMate AI

### Your Real-World Visual Assistant

VisionMate AI is an AI-powered visual assistant that helps users understand images, read text, explain study material, answer questions about images, and provide accessible visual descriptions.

## ✨ Features

- 📷 Image Understanding
- 🔍 General Image Analysis
- 📖 Text Reading
- 🧠 Study Material Explanation
- ♿ Accessibility Mode
- 💬 Ask Questions About Images

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini AI
- Google GenAI SDK
- python-dotenv
